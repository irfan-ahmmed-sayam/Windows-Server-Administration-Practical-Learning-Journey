# Day 15 | DNS (Domain Name System) – Theoretical Discussion

## 📌 Overview

This documentation covers the theoretical concepts of DNS (Domain Name System) in Windows Server 2016.

DNS is a fundamental component of network infrastructure that translates domain names into IP addresses and helps devices locate network resources.

In this session, I explored DNS architecture, DNS resolution, DNS records, DNS queries, and different DNS configuration concepts.
