# Day 16 | Windows Server 2016 – DNS Server Configuration

## Project Overview

In this lab, I practiced DNS Server configuration in a Windows Server 2016 environment using three servers.

I configured a dedicated DNS Server on Server 3 and performed DNS mapping for Server 1 and Server 2 using Forward and Reverse Lookup Zones.

## Lab Environment

- **Server 1:** Domain Controller (DC)
- **Server 2:** Member Server
- **Server 3:** Dedicated DNS Server
- **Domain Name:** avc.com

1. DNS Server Role Installation and Configuration
2. DNS Zone Creation
3. Forward Lookup Zone Configuration
4. Reverse Lookup Zone Configuration
5. SOA and NS Records
6. Host (A) Record Creation
7. PTR Record Configuration
8. CNAME Record Configuration
9. DNS Name-to-IP Mapping
10. IP-to-Name Resolution
11. DNS Testing Using Ping and NSLookup Commands
