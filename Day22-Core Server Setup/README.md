# Day 22: Windows Server Core Setup & Basic Configuration in VMware

## Overview

In this session, I worked on setting up **Windows Server Core in VMware** and performing its initial configuration using PowerShell.

I also explored the differences between Windows Server Core and Windows Server with Desktop Experience (GUI), along with an overview of Windows Server Standard and Datacenter editions.

The main focus of this practical session was to understand the Core Server environment and perform its essential initial configurations through the command-line interface.

- Testing Connectivity Using IP Address
- Testing Connectivity Using Hostname
- Verifying Communication Between Servers
