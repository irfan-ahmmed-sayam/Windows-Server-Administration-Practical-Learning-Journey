# Day 18 | Windows Server | DHCP Server Role Install and Scope Configuration

## 📌 Project Overview

In this lab, I worked on DHCP Server configuration in Windows Server.

I installed the DHCP Server Role, configured an IPv4 DHCP Scope, and verified that client computers could automatically receive IP addresses from the DHCP Server.

I also prepared theoretical notes to understand the basic concepts of DHCP and its configuration.
