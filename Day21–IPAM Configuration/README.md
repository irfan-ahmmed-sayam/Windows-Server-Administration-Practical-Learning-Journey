## Day 21 – IPAM (IP Address Management) Configuration & Centralized DNS/DHCP Management

### Overview
In this session, I explored IPAM (IP Address Management), a Windows Server feature used to centrally monitor and manage network IP address spaces, DNS Servers, DHCP Servers, and other network resources from a single management console.

The practical implementation includes installing the IPAM feature on a Member Server, configuring the IPAM Server, and completing all six steps of the IPAM provisioning process.

### Topics Covered

**1. IPAM Fundamentals**
- Introduction to IPAM and its purpose.
- Reasons for using IPAM in enterprise networks.
- Main functions and components of IPAM.
- Advantages and limitations of IPAM.
- Server Inventory and Server Discovery.
- Address Space and IP Address Inventory.
- IP Address Tracking.

**2. IPAM Installation & Configuration**
- Installing the IPAM Feature on a Member Server.
- Configuring the IPAM Server.
- Understanding the IPAM Provisioning Process.
- Completing all six IPAM configuration steps.
- Configuring Server Discovery.
- Managing servers through IPAM.

**3. Centralized DNS Management**
- Managing DNS Servers through IPAM.
- Creating DNS Zones.
- Viewing existing DNS Zones.
- Modifying existing DNS Zone configurations.

**4. Centralized DHCP Management**
- Managing DHCP Servers through IPAM.
- Creating DHCP Scopes.
- Viewing existing DHCP Scopes.
- Modifying existing DHCP Scope configurations.
- Managing DHCP resources from a centralized console.

### Practical Outcome
Successfully configured IPAM on a Member Server and established a centralized management environment for DNS and DHCP infrastructure. Verified how to create, manage, and modify existing DNS Zones and DHCP Scopes directly through IPAM.
